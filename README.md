# 法院文书下载工具

## 启动方式
```
cd court-scraper
node server.js
```
然后打开浏览器访问：http://localhost:3847

## 使用方法
1. 粘贴法院送达短信链接
2. 点击"解析文书"，等待解析完成
3. 在文件列表中勾选需要下载的文件（或全选）
4. 点击"打包下载"，ZIP 文件将自动下载

## 功能特性
- 自动检测送达链接是否已过期，过期时显示明确提示
- 显示下载链接有效期截止时间
- 支持单独下载或批量打包下载

## 注意事项
- 送达链接有效期约 24 小时，过期后需重新获取
- 打包下载前请先关闭所有代理插件，否则可能下载失败
- 本工具调用法院官方 API，不缓存任何文件
